# 非数据型图示规划与交付报告

## 1. 规划结论

依据 `ANALYSIS_MODELING_REPORT.md`、`RESULTS_REPORT.md` 与 `figures/` 中已有统计图，本阶段保留三张对论文叙事有实质作用的非数据型图示：总体技术路线、无数据泄漏的数据流程、滚动调度结构。三图分别回答“全文如何组织”“数据何时可见”“策略怎样滚动执行”，不复画曲线、柱状比较、预测效果或逐日收益等数据图。

| 图示 | 论文作用 | 主要依据 | 建议插入位置 | 交付文件 |
|---|---|---|---|---|
| 总体技术路线图 | 展示四问从确定性优化到不确定调度、滚动调整和波动价格扩展的递进关系，并统一数据、模型、结果和验证口径 | 两份报告中的四问结构、统一 LP 物理约束、基线比较与验证框架 | “问题分析”末尾或“模型总体框架”开头；建议整页纵向排版 | `fig_roadmap.drawio`、`fig_roadmap.pdf` |
| 数据门禁与无泄漏建模流程 | 明确四类附件、字段检查、单位换算、信息集切分、历史窗口、当日轨迹结算和独立回代验证 | 报告中的数据清洗规则、时间可得性约束和预测防泄漏要求 | “数据预处理”或“预测模型”章节 | `fig_pipeline.drawio`、`fig_pipeline.pdf` |
| 多时点预报驱动的滚动购电与储能调度 | 解释 0/6/12/18 时点更新、历史可见信息、残差分位数裕度、滚动 LP、冻结已执行决策及 SOC 继承 | 问题三与问题四的滚动求解机制和真实实现口径 | “问题三模型建立”中滚动优化公式之后；问题四可直接引用 | `fig_model_mpc.drawio`、`fig_model_mpc.pdf` |

建议图题分别为：

1. 微网购电与储能协同调度总体技术路线；
2. 数据门禁、信息集切分与无泄漏建模流程；
3. 多时点光伏预报驱动的滚动购电与储能调度机制。

## 2. 与既有统计图的边界

现有 `fig01`—`fig06` 已覆盖输入曲线、问题一调度、模型目标值比较、预测示例、逐日节省和电价预测。本阶段没有绘制折线图、柱状图、分布图、热力图或任何由结果数值重新编码的图形；图中的容量、功率、效率、时点和残差分位数仅作为模型机制标注，不承担统计比较功能。

特别地，总体路线图中的“基线—主模型比较”只表示验证步骤，不复述 `fig03_model_comparison.pdf` 的数值；滚动调度结构图也不复画 `fig04_prediction_example.pdf`、`fig05_q3_daily_savings.pdf` 或 `fig06_price_forecast.pdf`。

## 3. 主动省略的候选图

| 省略项 | 原因 |
|---|---|
| 四张逐问求解流程图 | 四问共享同一物理约束与求解主线，拆成四图会与总体技术路线和滚动结构图大面积重复 |
| 独立的问题一 LP 流程图 | 确定性 LP 结构简单，公式与约束表比流程图更准确 |
| 独立的问题二预测—优化流程图 | 已由“无泄漏建模流程”覆盖历史窗口、预测裕度与优化接口 |
| 独立的问题四动态电价框架图 | 问题四只是价格输入与多次更新机制的扩展，可在总体路线和滚动结构图中说明 |
| 指标体系或权重层级图 | 本题是预测与优化题，不是多指标综合评价题；人为构造权重体系会偏离题意 |
| 结果仪表盘或结论信息图 | 会与既有数据图重复，而且不利于论文中追溯真实结果来源 |

## 4. 质量与可复用性检查

- 三个 `.drawio` 文件均通过 XML 解析，可在 diagrams.net 中继续编辑。
- 三个 PDF 均为单页矢量导出；`pdfimages -list` 未发现嵌入位图对象。
- 同时保留 PNG 预览，仅用于快速审阅，不建议在论文中替代 PDF。
- 完成两轮视觉检查。第一轮发现数据流程图右下方验证节点拥挤、滚动调度图反馈线穿越主流程；第二轮已分别下移验证区、上移反馈回路，复查后未见文字溢出、节点遮挡或箭头压字。
- 颜色语义保持一致：蓝色表示任务/输入，橙色表示预处理或费用环节，紫色表示预测与不确定性，青色表示优化、能量平衡或验证。
- 静态结构检查未发现孤立关键节点、空标签或页面外元素。

## 6. 使用注意

总体技术路线图适合纵向整页；另外两张横图建议跨双栏或横向整页。论文正文应结合公式解释图中的“统一物理约束 LP”“残差 80% 分位数裕度”和“只优化尚未执行时段”，避免将其误写为已经实现的完整情景 CVaR 模型。
